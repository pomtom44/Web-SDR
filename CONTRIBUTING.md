# Contributing

Thanks for your interest in contributing to Web-SDR.

## Getting started

1. Fork the repository and clone your fork.
2. Create a branch for your change: `git checkout -b my-change`.
3. Make your change and commit with a clear message.
4. Push to your fork and open a pull request against `main`.

## Pull requests

- Keep PRs focused on a single change where possible.
- Describe what the change does and why in the PR description.
- Link any related issues.

## Reporting issues

Use the issue templates under **New Issue** to report bugs or request features.
